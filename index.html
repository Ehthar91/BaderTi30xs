Bader TI-30XS User Manual

This manual explains the browser calculator included on this page. It is designed to follow the documented TI-30XS MultiView feature set as closely as practical in a web interface.

Tip: Green labels are secondary functions. Press 2nd, then the corresponding key.

1. Getting started

Use the on-screen keypad or your computer keyboard. Press ENTER to evaluate an expression. The calculator keeps recent history so previous entries can be recalled with the up/down navigation controls.

  • 2nd activates the green secondary label.
  • ON wakes the calculator.
  • 2nd + ON turns the display off while retaining state.
  • The browser version also includes an automatic power-down timer of about 5 minutes.
  • 2nd + + increases LCD contrast and 2nd + − decreases it.

2. Modes

Press mode to choose:

SettingOptionsPurpose
AngleDEG, RAD, GRADControls trig input and output angle units.
NotationNORM, SCI, ENGControls numeric result display.
DecimalFLOAT or 0–9Controls the number of decimal places shown.
DisplayCLASSIC, MATHPRINTClassic uses a single-line style; MathPrint uses textbook-style structures.

2nd + mode quits back to the Home screen.

3. Editing, cursor movement, history

  • Arrow keys move through the current expression.
  • 2nd + left/right jumps to the beginning/end.
  • delete deletes at the cursor.
  • 2nd + delete toggles Insert mode.
  • clear clears the current entry.
  • Up/down navigates stored history when not moving inside a fraction/template.

4. Fractions, mixed numbers & percentages

  • n/d inserts a fraction template.
  • 2nd + n/d inserts a mixed-number template.
  • 2nd + ×10ⁿ converts between improper and mixed fraction display when applicable.
  • f↔d toggles fraction/decimal answers.
  • The white ↔ answer-toggle key also switches exact/decimal forms when available.
  • 2nd + ( applies percent %.
  • 2nd + ) converts to percent.

Fractions are simplified automatically. Common exact square-root and π forms are preserved in MathPrint when possible.

6. Trigonometry, hyperbolics & angle tools

  • sin, cos, tan use the active angle mode.
  • 2nd + sin/cos/tan gives inverse trig.
  • 2nd + π toggles HYP; then use sin/cos/tan for hyperbolic functions.
  • Use 2nd + prb to open the Angle menu.

The Angle menu includes degree, minute, second, radian, gradian modifiers, DMS conversion, and rectangular/polar coordinate conversion.

7. Probability & random numbers

Press prb for:

  • nPr permutations
  • nCr combinations
  • ! factorial
  • RAND submenu with rand and randint(

You can store a nonnegative integer seed to rand from the Store menu to make the browser's random sequence repeatable.

8. DATA editor & statistics

Press data to edit L1, L2, and L3. Each list can hold up to 42 items. The editor includes individual list clearing, Clear ALL, and formula controls.

Press 2nd + data for STATS:

  • 1-Var Stats: n, x̄, Sx, σx, Σx, Σx², MinX, Q1, Med, Q3, MaxX.
  • 2-Var Stats: x/y means, sample/population deviations, sums, Σxy, linear-regression slope a, intercept b, correlation r, and prediction tools.
  • StatVars appears after a statistics calculation.

9. Function table

Press table to define a function in x.

  • Start sets the first x value.
  • Step sets the increment and cannot be 0.
  • Auto generates a series automatically.
  • Ask-x lets you enter specific x values manually.

10. Constant K

Press 2nd + ÷ to define Constant K. Enter an operation such as *2+3. After K is enabled, pressing ENTER applies the stored operation to the current entry or last answer. Use the K menu again to turn it off or change it.

11. Variables, Ans, Store & Recall

  • The calculator has variables x, y, z, t, a, b, c.
  • vars inserts a variable.
  • 2nd + vars opens Clear Var.
  • sto→ stores the current answer.
  • 2nd + sto→ opens Recall Var.
  • 2nd + (−) inserts Ans.
  • 2nd + 0 opens Reset.
